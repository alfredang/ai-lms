AI Configuration

Configure the AI assistant to use your preferred provider:

Supported Providers

ProviderModelsFeatures

Configuration Options

  • Provider: Select your AI provider
  • API Key: Enter your provider API key (stored encrypted)
  • Model: Choose the specific model to use
  • Max Tokens: Set maximum response length
  • Temperature: Adjust response creativity (0-1)

API Key Management

Securely store and manage API keys for external services:

  • OpenAI API Key: For AI chat features
  • Google OAuth: For Google sign-in
  • GitHub OAuth: For GitHub sign-in
  • Stripe Keys: For payment processing
  • PayPal Credentials: For PayPal checkout
  • Resend API Key: For email notifications
Security Note

All API keys are encrypted before storage. Never share your API keys or commit them to version control.

Payment Settings

Configure payment processing for paid courses:

Stripe Integration

  1. Get your API keys from the Stripe Dashboard
  2. Enter your Publishable Key and Secret Key
  3. Configure webhook endpoint for payment events
  4. Set up products and prices in Stripe

PayPal Integration

  1. Create a PayPal Developer account
  2. Get your Client ID and Secret from the dashboard
  3. Configure sandbox mode for testing
  4. Switch to live credentials for production

System Maintenance

Additional superadmin responsibilities:

  • Review security logs and access patterns
  • Manage badge and gamification settings
  • Configure email templates and notifications
