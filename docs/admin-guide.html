Admin Dashboard

The Admin Dashboard provides a high-level overview of platform activity:

Total Users

View user counts by role and recent signups.

Active Courses

See published courses and enrollment statistics.

Enrollment Metrics

Track enrollments, completions, and drop rates.

Recent Activity

View the latest platform actions and events.

User Management

Admins can manage all platform users:

  • View Users: Browse all registered users with filtering and search
  • Edit Profiles: Update user information and profile pictures
  • Change Roles: Promote or demote users between Learner, Trainer, and Admin
  • Suspend Accounts: Temporarily disable user access
  • Reset Passwords: Send password reset links to users
